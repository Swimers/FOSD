# Classic 通信日志与通道标定改进（2026-11-07）

本轮完成本地地址独立刷新、曲线通道筛选迁移、三种通信方式的彩色收发日志，以及旧二维页面移除和标定入口迁移。复用现有网卡枚举、通信收发、参数配置与持久化接口，未增加设备协议或修改解包流程。

## 界面与功能

| 改动 | 当前行为 |
| --- | --- |
| 本地地址刷新 | `cbox_LocalIP` 旁新增 `pbtn_RefreshLocalAddress`，重新枚举 IPv4 地址；原地址仍可用时保留选择，否则回退到有效项。可用于插入新网卡后的手动刷新。 |
| 通道筛选 | `groupBox_select` 移到 `tab_guangpu`，只影响波长曲线；波长表、解算和存储保留全部通道。其他标签页不显示筛选组。 |
| 收发日志 | 串口、UDP、TCP 均显示毫秒时间戳、通信方式、RX/TX、端口信息、字节数与内容预览。每条记录独占一行，接收绿色，发送蓝色；历史记录随深浅主题调整颜色。 |
| 显示模式 | 三种通信方式均可切换 Hex / UTF-8。换行符显示为 `\r`、`\n`，保持单条记录完整；串口和 TCP 的 UTF-8 解码保留跨接收回调的状态。 |
| 日志负载 | 每种通信最多保留 200 条，载荷预览最多 64 字节（字符串最多 64 字符），每 60 秒清空。界面增量追加，避免持续复制全文。有效 UDP 包保留解析摘要，显示刷新周期内合并为最新包；不重复输出原始载荷。 |
| 标定迁移 | 删除主导航 `pbtn_2DPlot`、`disp2dwindow` 及其专用 Backend/Presenter。原 `disp2dpara` 更名为 `channlCalibration.ui/.cpp/.h`，归入 connection 模块；通过通信页“通道与系数标定”按钮打开。 |
| 标定参数 | 配置 HYY 的 12 路输入源序号和校准倍率，沿用后端合法性校验与持久化。打开时读取有效配置；取消后重新打开恢复已生效值。应用前需完成置零或读取有效标定配置。 |

新增、移动及删除控件均通过 `.ui` 完成。C++ 负责绑定、数据、格式和主题。

发送日志标记为“TX 发送请求”，表示数据已提交给通信层，不代表下位机确认或实际送达。串口显示配置的 COM 名称和波特率；UDP 显示来源/目标与配置的本地端口；TCP 显示服务端监听端口或客户端目标端口。系统自动分配的本地端口当前没有后端查询接口，日志明确显示“自动端口/本地系统分配端口”；TCP Server 在收到首条数据前不推测客户端端口。

## 验证

Release 使用 MSVC 2017 x64、Qt 5.12.2、VTK 8.2 构建，完整 CTest 17/17 通过。新增/调整验证覆盖：

- 本地地址刷新、当前地址保留、筛选组所在标签页、二维导航移除，以及只筛曲线时波长表仍保留全部记录。
- 标定入口、参数回显、合法值持久化、越界拒绝、取消与重新打开。
- 真实 UDP 回环和 TCP Client/Server 对端收发，检查发送字节、时间戳、端口和 RX/TX 日志。
- 串口通过接收信号及发送请求注入验证日志；三种通信的 Hex/UTF-8、浅色/深色配色、上限与定时清理。
- 保留 MP 解包回环、存储、解算和可视化等既有回归测试。

已检查实际窗口截图。未连接真实串口硬件或新插入的物理网卡，也未在另一台电脑进行验收。
