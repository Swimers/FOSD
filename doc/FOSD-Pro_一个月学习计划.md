## 第 4 周：综合实践与最终交付

### 最终任务：通信数据日志记录器

| 维度 | 内容 |
|:---|:---|
| **任务目标** | 为 `connectwindow` 增加串口 / UDP / TCP 通信数据的十六进制日志记录功能 |
| **界面要求** | 添加“开始记录 / 停止记录”按钮与状态显示标签 |
| **文件要求** | 日志按通信类型保存到 `./logs/`，文件名含时间戳，自动创建目录 |
| **格式要求** | `[YYYY-MM-DD HH:MM:SS.zzz] RX: FA FB ...` |
| **技术要求** | 记录操作不得阻塞通信线程，需保证线程安全 |
| **关键产出** | ① 可运行的改进代码；② 测试通过的日志文件；③ 包含文件路径、格式、测试方法的 README |
